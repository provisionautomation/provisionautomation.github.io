GETTING STARTED
---------------
1. Open "Provision Automation.xlsm".
2. Enable Macros/Content when Excel asks.
3. The software includes a 7-day trial period.
4. After the trial expires, an activation key is required.

ACTIVATION
----------
When requesting an activation key, provide the Computer ID 
shown in the LICENSE section of the workbook.

Select the license duration you purchased:
- 1 Month
- 3 Months
- 6 Months

An activation key will be provided after payment is confirmed.

IMPORTANT
---------
Do not rename or modify the Excel workbook.

The license is associated with the computer used for activation.
